# Boletera - SICOPATH

#  Problematica
Identificamos que una gran parte de la poblacion estudiantil depedende del transporte escolar, estimando que al menos 1,600 alumnos utilizan este servicio. Analizando 


# Objetivo general

Desarrollar una plataforma para computadoras y dispositivos moviles que nos permia gestionar la compra y uso de boletos para el transporte escolar usando un sistema de recargas de saldo y generacion de códigos QR.

# Objetivos especificos

* Implementar un sistema a la comunidad estudiantil para obtener los boletos de transporte escolar de manera digital.
* Desarrollar un sistema de generación de codigos QR que permita la validación de boletos a la hora de abordar el transporte escolar.
* Disminuir las filas y tiempos de espera en los puntos de venta.
* Implementacion de sistema de autenticación con correo escolar o whatsapp para asegurarnos que la aplicacion sea usada por estudiantes autorizados.
